让 App 连接你的浏览器

适用于 Mac 和 Windows 上的 Chrome、Microsoft Edge。首次安装一次，以后保持浏览器和 App 打开即可。

商品运营台已携带本机连接服务。你只需在日常操作店铺的浏览器里安装 Kimi 浏览器扩展（原 Kimi WebBridge），无需另装 Node、Python 或运行安装命令。

  1. 打开日常操作店铺的浏览器

    使用 Chrome 或 Edge，并将它设为系统默认浏览器。若浏览器有多个个人资料，选择平时登录店铺的那一个；扩展需要安装在同一份浏览器个人资料里。

    当前不支持 Safari、Firefox。每台电脑都需要单独安装扩展。

  2. 从 App 取出扩展安装文件

    打开商品运营台左下角的“浏览器连接 · 安装教程”，点击“打开上一级并选中文件夹”。

    App 会把官方 ZIP 和解压后的文件夹保存到你的文稿／文档 → 商品运营台浏览器扩展目录，并打开上一级目录、选中 Kimi浏览器扩展 文件夹。也可点“复制文件夹路径”。选中的文件夹里能看到 manifest.json，不需要自己解压。

    请保留这个文件夹。浏览器以后仍要读取它，不能删除或移到临时目录。

  3. 把扩展加载到浏览器

    浏览器在地址栏输入
    Chromechrome://extensions/
    Edgeedge://extensions/

    打开“开发者模式”，点击“加载已解压的扩展程序”（Edge 可能显示“加载解压缩的扩展”）。选择上一步选中的、含 manifest.json 的 Kimi浏览器扩展文件夹。

    也可在选择文件夹时粘贴路径：Mac 按 ⌘⇧G，Windows 在地址栏粘贴。选择的是文件夹，不是 ZIP 文件，也不是上一级目录。加载后应能看到名称为 Kimi 的扩展，并保持启用。可将它固定到工具栏。

  4. 回到 App，重新检测

    安装后先点击“重新检测”，无需先手动填写连接地址。出现绿色的“浏览器已连接，可以开始填写商品”后，点击“完成”。

    然后按原流程操作：导入 Excel → 核对并保存 → 选择店铺 → 开始填写并保存草稿。安装扩展本身不会登录店铺；遇到验证码，需在浏览器中完成。

如果还没连接上

需要手动开启连接或填写地址吗？

官方扩展新装后默认自动连接本机服务，不需要手动开启开关。App 显示“浏览器已连接”时可直接使用。只有仍未连接时，才进入扩展设置的“本地 agent 远程控制”栏目，检查“连接地址”是否与 App 一致。

通常地址为 ws://127.0.0.1:10086/ws；如扩展中已是此地址，不用重复填写。若之前断开过连接或改过设置，且 App 仍使用默认端口，可在“连接地址”中点击“恢复默认”后重新检测。若 App 显示其他端口，使用 App 的“复制连接地址”再修改。

已经装过，为什么仍显示未连接？

先确认浏览器已打开、Kimi 扩展已启用、安装在正确的个人资料中，并核对连接地址。App 能检测连接，无法仅凭断连判断“没有安装”；因此请先检查已有扩展。

提示本机连接服务不可用

重新检测一次。仍失败时，保留商品资料并关闭后重新打开 App。端口占用或内置文件缺失时，请把 App 的提示交给管理员；不要自行关闭其他软件正在使用的桥接服务。

提示版本不匹配

当前 App 附带的扩展及服务版本为 2.0.22。已有桥接服务会被复用，App 不会自动升级或重启它。请把窗口中显示的版本信息交给管理员，按官方说明统一配套版本。已连接的电脑无需重新安装。

只想先整理商品资料

可点击“稍后再装”。Excel 导入、编辑和保存仍可使用；执行浏览器填写和店铺登录前，App 会重新检测连接。
