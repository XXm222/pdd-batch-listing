修复
切店后绑定错店：只有最终核对成功的同一份页面信息里同时拿到后台店铺 ID 与账号 ID 才写入店铺；切店过程中新页面还没读到编号时，不再沿用上一家店的绑定。
报价被自动改动：导入与编辑器不再把 39.90 改成 40；公式算出的超两位小数只提示，运营点「金额取整」才应用。参考价同理，点「参考价填 X」才写入。
导出再导入丢字段：导出按模板实际表头写「到店安装 / 安装类型 / 模板」与每行「轮辋直径」；类目属性写到真正的「属性名称」表头下面；采集来源不再占用「安装类型」那一行。
读模板串店、改动后台勾选：读取前先核对当前编辑页属于目标店铺，不是就停下来说明；读取改为只读，不再替运营勾选「到店安装」。
商品自己选的模板被覆盖：商品明确填写模板时保留原值，只有留空才用店铺记住的默认模板；草稿读回逐项核对安装类型、模板 ID 与每个 SKU 的轮辋直径，缺一项就判不一致。
