# Design System: 商品运营台

## Overview

**Creative North Star: "本机运营工作空间"**

面向日常运营的桌面工具，以中性浅灰背景、白色工作区、蓝色主要动作和系统中文字体保持清楚、克制的操作层级。Mac 与 Windows 共用业务界面；当前产物是浏览器原型，不模拟操作系统窗口装饰。

资料识别和本机保存使用实际读取结果；店铺登录与草稿执行使用演示状态。文字、状态和记录共同说明能力边界，避免用视觉上的成功状态替代真实后台结果。

**Key Characteristics:**

- 浅灰背景与白色工作区
- 蓝色动作与选中状态
- 中文系统字体与紧凑表单
- 导入、确认、本机保存、选择店铺的顺序清楚可见
- 本机资料状态与模拟执行状态有文字说明

## Colors

以蓝色作为唯一主要动作色，中性色承载密集资料，绿色与琥珀色说明状态。

### Primary

- **操作蓝**：主按钮、流程当前步骤、文字动作和选中状态。
- **深操作蓝**：主按钮悬停。
- **浅蓝底**：导入图标和模拟执行进度。

### Neutral

- **外层灰底 / 工作背景 / 白色表面**：窗口外、主内容区与资料容器。
- **导航灰底 / 导航选中底**：侧栏与当前位置。
- **墨色 / 次要灰**：主要内容、说明及标签。
- **分隔线 / 字段边框 / 按钮边框**：用轻边界区分容器与控件。

绿色与浅绿底用于“资料完整”或“模拟完成”；琥珀色与浅黄底用于“待补充”。识别问题横幅使用更浅的暖色背景。

**The 状态有文字 Rule.** 状态必须携带“资料完整”“待补充”或“模拟完成”等文字，不能只靠颜色说明结果。

## Typography

**Display Font / Body Font:** 使用前置系统字体与 PingFang SC、Microsoft YaHei 的共用回退栈，见 frontmatter；当前 CSS 没有单独的 Windows 字体覆盖。

清晰的中文标题与紧凑的表格、标签共用同一字体。保持原有工具身份，无装饰展示字体。

### Hierarchy

- **Headline**：页面标题；720px 以下改为 24px，字重与行高保持。
- **Dialog title**：识别、店铺选择、账号与模板弹窗标题。
- **Title**：导入区、资料库与店铺名称；720px 以下导入区标题为 16px。
- **Subsection**：识别表单的小节标题。
- **Body**：普通页面内容；行高 1.6。
- **Control**：普通按钮、表格内容、识别基本资料输入框。
- **Label**：字段标签、说明、表头与搜索输入；表头字重 500。
- **Caption**：商品附注、识别商品列表说明和状态标签。

规格表与图片文件名输入使用 12px；账号表单输入继承正文的 14px。现有状态栏与图片文件名缩略标注使用 10px，只记录该局部实现，不作为正文或输入的字号规则。当前代码没有 tabular-nums 设置。

## Layout

以有边界的桌面工作空间组织内容：窗口最大宽度 1560px，默认上下外边距 24px、最小高度 calc(100vh - 48px)。侧栏宽 192px，顶部栏高 60px，主内容内边距 32px 36px 0。三个导航入口是商品资料、店铺管理、执行记录。

商品资料页先显示四步流程和较大的双入口导入区，随后显示本机商品资料库。导入区内边距 25px 28px，入口两列等宽、间距 16px；资料库上方间距 32px。表格允许横向滚动，批量选择店铺栏贴在内容底部。店铺卡片两列、间距 20px。

识别弹窗宽 1080px，左侧商品列表 220px，右侧编辑区独立纵向滚动；内容高 min(580px, calc(100dvh - 290px))、最小高 260px。店铺选择弹窗宽 640px；账号与模板弹窗宽 520px。所有弹窗最大宽 calc(100vw - 32px)、最大高 calc(100dvh - 40px)。基本资料表单两列，标题与类目占整行；规格表最小宽 470px，横向滚动。

| 窗口范围 | 当前布局行为 |
| --- | --- |
| 至少 1700px | 窗口上边距 32px，最小高 calc(100vh - 64px) |
| 至多 1250px | 窗口铺满视口，去窗口外边框与圆角；侧栏 172px，主内容 26px 28px 0 |
| 至多 1000px | 侧栏 154px；主内容 24px 22px 0；店铺卡片单列；识别列表 180px |
| 至多 720px | 侧栏 64px，仅显示图标；顶部栏 50px；主内容 20px 16px 0；流程两行、导入入口单列、搜索全宽 |

720px 以下识别商品列表改为 85px 高的横向滚动条目，条目最小宽 145px，表单单列。弹窗页脚纵向排列、按钮组靠右；任务记录纵向排列。侧栏品牌文字与页脚、顶部草稿标签、店铺选项状态标签在该窄屏范围隐藏。

## Elevation & Depth

普通工作区、店铺卡片和列表以白底与轻边框分层，不使用卡片阴影。窗口、弹窗和短暂反馈使用柔和阴影，弹窗遮罩为 #1c294265，背景模糊 2px。

### Shadow Vocabulary

- **窗口**：`0 16px 60px #2631490b`。
- **弹窗**：`0 22px 100px #1c294230`。
- **短暂反馈**：`0 6px 24px #182c4430`。

**The 平面工作区 Rule.** 普通资料容器用背景和边框分层；阴影只用于窗口、弹窗与短暂反馈。

## Shapes

圆角按控件大小递进：状态标签、字段、按钮、导航、导入入口、资料容器、导入区与窗口分别对应 frontmatter 的圆角。商品缩略图与图片预览使用字段圆角。窗口和弹窗使用同一较大圆角。

统一使用内联轮廓 SVG，默认 20px、线宽 1.6px，端点与连接圆润；导入入口图标 28px，卡片店铺图标 26px。流程数字采用 25px 圆形，勾选与单选框 16px。

## Components

### Buttons

主按钮蓝底白字，次按钮白底墨色文字，均为 13px、常规字重，内边距见 frontmatter，最小高 40px。主按钮悬停变深蓝；次按钮悬停底色 #f7f9fc。文字动作蓝色、13px、6px 0 内边距，悬停加下划线。禁用透明度 .45、默认光标。

所有交互控件的键盘焦点使用 `3px solid #3154bd55`，偏移 3px。按钮、导入入口与导航仅在 prefers-reduced-motion: no-preference 时使用 background / border-color 的 .15s 过渡；当前没有 toast 进出动画。

### Chips

资料状态标签为 11px、3px 7px 内边距、轻圆角，不承担点击行为。绿色标签说明资料完整或模拟完成，黄色说明待补充。文字区分本机检查与模拟执行结果。

### Cards / Containers

资料库、店铺卡片与任务列表用白色表面、1px 分隔线和资料容器圆角。店铺卡片内边距 24px；导入区采用更大圆角与 25px 28px 内边距。导入入口用 #fbfcfe 底、#dce2ed 边框，悬停为 #f6f8ff 底和操作蓝边框。

### Inputs / Fields

输入用白底、墨色、字段边框与字段圆角。普通内边距 9px 10px；规格输入为 7px 8px。识别基本字段字号 13px，规格与图片文件名为 12px，搜索为 12px。搜索容器有边框，内部输入没有自己的边框；搜索框局部的 outline:none 覆盖不作为公共焦点规范。

识别问题横幅用暖色背景、12px 文字和 10px 12px 内边距，说明缺失字段及恢复方法。不引入当前源码没有的红色错误样式。

### Navigation

侧栏导航默认次要灰，14px、13px 14px 内边距；悬停底色 #e7ebf2，当前页用浅蓝底、蓝字、600 字重。图标与文字间隔 12px。1000px 以下导航为 13px、12px 10px 内边距；720px 以下文字隐藏、居中图标 21px、13px 内边距。当前页使用 aria-current。

### Recognition / Shop Selection

识别商品条目以左列选择、右列编辑组织。当前条目为白底、#b8c7ec 边框，标题 13px、500 字重，说明 11px。保存商品资料后才勾选完整商品并进入目标店铺弹窗；待补充资料可保存，但不能用于执行。

店铺选项为带单选框的有边界条目，默认 17px 内边距、间距 14px；选中后为蓝边框和 #f7f9ff 底。店铺管理仅名称、账号、密码三个字段。原型数据库只保存 credentials 布尔标记，密码输入清空；本机商品、图片 Blob 和模拟记录使用 IndexedDB。模拟记录保留当次目标店铺，登录与草稿执行明确标为模拟。默认动作是“开始保存草稿”。

## Do's and Don'ts

### Do:

- Do 保持浅灰背景、白色工作区、蓝色动作和共用中文系统字体。
- Do 使用“导入资料 → 确认识别结果 → 保存商品资料 → 选择店铺”的当前流程。
- Do 用文字说明资料状态、目标店铺和模拟执行结果。
- Do 让密集表格和识别编辑区在窄窗口继续滚动使用。

### Don't:

- Don't 把模拟登录或模拟完成写成真实商家后台已接入。
- Don't 把账号密码放入商品模板、任务记录或导出文件。
- Don't 把密码布尔标记描述成已保存真实密码。
- Don't 在当前资料工具界面添加装饰眉题、模拟系统窗口按钮或硬偏移阴影。
