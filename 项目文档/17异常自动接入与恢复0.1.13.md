# 异常自动接入与恢复 0.1.13

日期：2026-10-04。以运营最新要求为准：正常脚本独立运行，页面意外或脚本失败时 Agent 接入，能解决则自动继续；Excel 资料问题由运营补充。

## 角色与入口

- TaskRunner 负责完整正常流程、商品快照、队列、断点、计时和草稿结果；它不依赖模型才能运行。
- AgentService 负责页面异常处理。仅页面超时、表单异常/离开、上传或保存不确定自动接入；不在导入、每个点击或正常填表时调用模型。
- 模型未配置时，正常脚本照常运行；异常记录注明 Agent 不可用，不伪装模型已处理。
- 本机 Excel 缺字段/图片/规格矩阵问题直接提示资料补充，不消耗模型调用。模型发现资料不符合后台时也只能指出问题，不能自行改值。

## 默认行为

模型设置中，异常自动接入、原页字段读取和恢复后自动继续默认开启。开关与模型设置共同保存，不能因为留空保留密钥而丢失开关状态。可以关闭自动接入或自动继续。

发生异常后：脚本停止并持久化现场及脚本耗时 → 释放队列 → Agent 读取原任务与原页 → 调用允许的恢复工具 → 核对更新现场 → 输出结构化结果 → 自动继续原任务 → 继续原批次剩余待执行商品。AI 与脚本用时分别记录。

| 恢复工具 | 能做什么 | 限制 |
| --- | --- | --- |
| 关闭普通提示 | 关闭唯一普通通知的“知道了 / 关闭 / 稍后再说 / 暂不”按钮 | 不能点保存、提交、删除、账号、资质、授权、退款等业务确认 |
| 等待原表单 | 等待已核对店铺与编号的原填写页恢复 | 不切账号、不改商品 |
| 重开原填写页 | 使用已记录的 PDD 原编号 URL | 不新建商品；未确认图片上传时禁止刷新；当前若是其他商品则不导航 |
| 等待原上传完成 | 依据本任务完整提交记录，等待原轮播/详情图片全部完成并恢复上传记录 | 不补传、不删图、不凭外来图片数量认领 |

自动处理最多五轮模型请求、六次工具调用、约 120 秒。每任务最多自动交回脚本一次；继续后仍失败，保留原任务和记录，停止自动循环。运营随时可暂停，暂停后不继续操作或启动新执行。

## 数据与业务边界

- 原编号在分配后先持久化，再等待填写表单；减少加载失败后编号丢失的情况。
- 原表单已有正确规格前缀时，脚本仅补充缺失的维度或值；冲突组合不能删除或替换。
- 已写入保存意图，只能回查原草稿；模型不能再次点击保存或重新创建。
- Agent 不能修改价格、库存、服务承诺、店铺配置、凭据，也不能正式发布。工具不接收任意 JavaScript、选择器或 URL。
- 验证码/短信、店铺权限、账号配置变化和工具无法处理的页面改版不承诺自动解决；保留现场及处理结果。这是外部前提或现有能力限制，不能假报恢复成功。
- 当前工具覆盖普通通知、延迟加载、原页恢复及本任务上传完成确认，不是任意 DOM 改版修复器。
