三个页面和本机资料流程可运行；Mac 实际 `.app` 已启动并操作。当前只保存本机资料与待执行任务。该结果不能解释为账号自动登录、后台草稿保存或双平台正式交付已经完成。

## 编译与核心检查

`pnpm build`：Electron TypeScript、React TypeScript 与 Vite 构建通过。

`pnpm test`：5 项通过、0 失败，具体覆盖：

1. 原模板两页、命名空间 XML、单规格价格库存、商品链接不进入模型。

## 启动问题及修复

重新打包签名后，启动阶段读取系统钥匙串可能等待授权，导致窗口未出现。进程采样确认后台线程在 Security 的 SecItemCopyMatching / Keychain 读取中等待。

已将启动调整为仅检查目标系统与异步加密接口支持，窗口启动不读取钥匙串。实际密钥检查只在保存密码时进行，等待超过 45 秒返回未保存提示；加密失败不会写入密码明文。旧挂起的测试进程已终止，修复后的包正常显示窗口并载入旧商品资料。

系统授权、锁定钥匙串、正式签名后的凭据连续使用与其他电脑安装仍需要专门验收。当前仅做本机临时签名，不承诺更换签名后免授权。

## SQLite 与包内容读回

`scripts/verify-local-data.cjs verification/local-data`：2 商品、1 店铺、1 待执行任务、2 图片文件。店铺 JSON 不含密码，数据库未找到测试密码明文，任务包含固定商品快照。输出见 `verification/数据读回.json`。

`scripts/verify-package.cjs`：16 个界面构建、主进程、Worker、模板与资源文件逐字节一致；运行时 manifest 的版本、入口、生产依赖与源码一致。electron-builder 正常移除开发 scripts / devDependencies / build 字段，不要求 manifest 与开发文件全文相同。SQLite WASM 和 Worker 均在实际包内，模板与运营原模板字节一致。结果见 `verification/构建一致性.json`。

`codesign --verify --deep --strict`：本机临时签名校验通过。`hdiutil verify`：最终 DMG 镜像校验通过。SHA256 位于 `release/SHA256SUMS.txt`。签名校验并不等于 Developer ID 签名、公证或另一台电脑通过 Gatekeeper。

## 0.1.6 保存前待补充弹窗，2026-09-30

证据：verification/0.1.6/待补充弹窗.png、弹窗操作记录.json、构建一致性.json。包内文件与当前源码一致；临时签名和 DMG 校验通过。此轮证据为 Mac 单商品交互，Windows 真机及批量多商品没有据此宣称完成验收。
