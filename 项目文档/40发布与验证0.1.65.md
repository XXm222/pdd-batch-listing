# 0.1.65 发布与验证

2026-11-23 发布。正式安装包对应 [v0.1.65](https://github.com/XXm222/ecommerce-batch-listing/releases/tag/v0.1.65) 的源码提交 `6e5f47619486c36b2de1ae86344e181702e9378d`。GitHub Releases、公开安装包链接与应用内在线更新均已切到 0.1.65。

## 本版变化

- 兼容拼多多后台子账号带姓名和主账号名与店铺名不同的显示方式。切店后仅使用最终核对通过的身份绑定。[Issue #2](https://github.com/XXm222/ecommerce-batch-listing/issues/2)
- Excel 支持选文件夹及有缓存的常规公式，保留原始报价并提示超精度。导出与回导保留安装设置、轮辋直径和类目属性。
- 到店安装模板读取前核对店铺身份，草稿读回按安装模板和各个 SKU 的规格组合核对。
- 新增设置页，浏览器连接、模型、本机资料目录与软件更新集中在此。 [完整变更](../CHANGELOG.md)

## 验证范围

- Windows 与 macOS 的 [CI](https://github.com/XXm222/ecommerce-batch-listing/actions/runs/45138435822) 通过格式检查、类型检查、396 项测试和生产构建。使用隔离样本复验账号绑定、原价保留、普通 Excel 空服务项保存、安装字段和轮辋读回。
- 两平台安装包各核对 68 项已编译源码及资源，含 Excel 模板、WASM 与导入 Worker。macOS DMG 完整性和临时签名校验通过，使用隔离资料目录从 DMG 启动，确认设置页和版本。
- 在线更新清单使用现有 Ed25519 密钥签名。公开固定下载链接的完整文件与本地构建大小及 SHA-256 一致，旧版更新协议可读取并验证 0.1.65。GitHub 发布附件的服务端摘要与本机构建一致。
- Windows 包在 Mac 上交叉构建，Windows 实机安装升级和本轮真实店铺后台提交待复验。Mac 安装包尚未完成 Developer ID 签名或公证。
