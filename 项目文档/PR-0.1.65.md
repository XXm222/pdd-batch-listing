## 这一版解决什么

1. **店铺身份核对**：后台把子账号渲染成 `主账号:子账号(真实姓名)`、主账号名与店铺名不一致时，不再误报「未读取到完整登录账号」。注入页面的守卫与主进程用同一套规则（剥真实姓名、比后台店铺 ID / 账号 ID）。
2. **Excel 批量导入**：多份表格或整个文件夹一次导入，逐份容错（坏一份不影响其余）；单买价是公式、图片序号不连续、一张图被多个规格引用都能导入，同图只存一份。
3. **到店安装 + 轮辋直径**：资料可填到店安装开关、安装类型、模板（名称或 `SIST_` ID），规格可填轮辋直径；模板只选一次即按店铺记住；从规格型号自动识别轮辋直径。
4. **上架前检查**：库存为 0、参考价偏低、开了安装却没模板、缺轮辋直径这些「后台必拒」的问题在导入后直接提示。
