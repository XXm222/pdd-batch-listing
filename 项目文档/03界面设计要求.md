# 商品运营台界面设计要求

界面应像一款完整的桌面商品工具：清楚展示商品，保持操作连贯，长任务运行时仍能编辑其他资料。现有原型 3.1 作为流程参考，正式界面用 React 组件实现并继续打磨。

## 视觉方向

采用浅灰底色、白色内容区域、深色文字和单一蓝色主操作。颜色沿用当前规范作为起点：背景 #F5F6F8，正文 #252D3B，主操作 #3154BD。绿色和琥珀色只表达状态，并配文字说明。

以商品图片、标题、价格和资料状态为视觉中心。留白、字号和线条统一，减少重复边框和装饰卡片；不加入与导入任务无关的指标看板。好看由具体设计验收体现，React 本身不会自动提升界面质量。

## 桌面窗口

- 建议初始窗口约 1280 × 820，最小窗口约 1024 × 680，实施时按两系统实际窗口内容区调整。
- 使用系统窗口控制按钮与原生文件选择器，Mac 与 Windows 各自保留熟悉的窗口行为。
- 左侧固定三个入口：商品资料、店铺管理、执行记录。当前页面有清晰选中状态。
- 顶部只展示当前位置和必要状态。浏览器地址、调试端口、商品填写链接不出现在日常页面。
- 表格、图片和弹窗随窗口缩放；弹窗正文独立滚动，保存和取消按钮始终可见。

## 页面与组件

**商品资料页面**顶部保留上传 Excel 和选择文件夹两个明确入口。下方展示已保存商品，缩略图配标题和商品编码；价格、规格数量、状态及编辑入口紧凑排列。批量选择操作放在列表附近。

**识别结果弹窗**左侧展示商品列表，右侧展示可编辑资料及图片。错误直接出现在对应字段旁，并提供缺失项目汇总。标题、类目与图片优先展示，v2 规格区逐行编辑 SKU 编码、最多两种规格类型和值、价格、库存及规格图，表格允许横向滚动；其他类目属性与服务承诺独立显示，折扣及运费设置放在可展开区域。缺图要显示具体文件名。

**店铺选择弹窗**仅在保存后打开。展示店铺名称、账号与密码保存状态，可直接添加店铺并返回原窗口选中新店铺。当前主按钮为“保存本机待执行任务”，明确尚未写入后台草稿箱；后台接入后才可保存后台草稿。Excel 不含目标店铺。

**店铺管理页面**沿用电商账单的平台区和店铺列表结构。当前平台为拼多多，列表支持按名称与账号搜索，显示店铺名称、脱敏账号和密码保存状态。选中店铺后可以编辑登录信息；添加／编辑弹窗为左侧标签、右侧输入的三行表单，保留名称、账号、密码三个业务字段。新增店铺名称为只读，从登录账号第一个中英文冒号前取名，账号格式为“店铺名:子账号”；新增弹窗聚焦账号。旧店铺编辑兼容现有名称与账号。密码不默认回显，编辑时留空保留密文、更换账号需要重填。真实登录接入前“检查登录”明确不可用。

**主页执行进度弹窗**在开始执行后自动打开，展示本次队列、目标店铺、当前商品、当前阶段、已确认保存件数、12 个步骤及逐步耗时。左侧商品队列可切换查看；运行中的商品变化时自动跟随当前件。正文独立滚动，底部操作保持可见。弹窗可以收起，主页保留“查看执行进度”入口；收起不会停止任务。暂停在当前操作退出后生效。异常处理与继续执行在弹窗内完成，尝试过保存的任务先“核对保存结果”。成功仅由已确认的任务结果显示，不用推测百分比或把待核对件数算作已保存。

**执行记录页面**仅展示已完成或已停止的结果，排队、执行中及 Agent 正在处理的任务在主页查看。保留历史结果、失败原因、分步耗时、日志、保存核验与清理/恢复；通过“在主页打开任务”进入对应进度弹窗。运行操作集中在主页进度弹窗，记录清理继续保护活跃任务及其队列。等待验证时提供去浏览器处理，失败时展示可处理的原因，保存结果未知时先核对后台。

## 字体与尺寸

中文使用 Mac 的 PingFang SC 与 Windows 的 Microsoft YaHei 等系统字体。正文建议 14px，辅助文字 12px，页面标题 26 至 28px，按钮高度约 40px；密集表格必须保留清楚的行间距。避免关键状态用很淡的小字表达。

## 交互状态

- 空白页面引导导入资料，不展示虚构生产数据。
- 读取期间显示正在识别，防止重复触发；失败后保留操作入口。
- 保存成功显示明确反馈，并在资料库出现对应商品。
- 资料不完整时解释原因，允许保存为待补充，禁止执行。
- 长任务显示真实阶段与逐件进度；没有总进度依据时不用伪造百分比。
- 密码更新、字段错误和店铺身份不符要展示可处理的信息。
- 支持键盘焦点、Tab 切换、Esc 关闭非执行中的弹窗和清晰的禁用原因。
- 动效只用于状态反馈，建议 120 至 180ms；遵守系统减少动态效果设置。

## 界面验收

在 Mac 和 Windows 上检查 1280 × 820、1024 × 680、系统缩放 125% 与 150% 的常用内容区域。标题不能被截断，价格和状态不能挤在一起，弹窗主按钮不能被遮挡。导入、识别编辑、资料保存、选择店铺和等待验证码均需有真实操作截图。

设计参考目录中的截图仅是原型证据，不能替代正式 React 桌面应用的验收截图。

0.1.4 运营填写调整：识别弹窗不显示测试字段，列表不显示测试徽标，不提供示例体验按钮。状态统一为本机检查通过；详情图允许长图；规格编码选填；商品品牌、运费模板和满件折扣可以暂留空，选店后确认。


0.1.6 待补充提醒：点击“保存商品资料”时，如果存在问题，弹出“商品资料还需补充”窗口，按商品分组展示具体问题；点击“返回修改”或 Esc 回到原编辑弹窗且保留输入，支持“修改此商品”切到指定商品。“仍保存为待补充”是单独的明确操作，保存后商品保持不可执行。编辑弹窗底部固定显示问题数量和“查看问题”入口，完整问题不再埋在图片后的长页底部。待补充窗口使用独立标题标识、键盘焦点和滚动正文。纯空格的未填尾部规格不视为一个规格选项。

0.1.7 运营交互修正：同编码资料在识别时提示，核对变化后明确更新或跳过；更新替换整份商品资料并保留原商品标识。商品与店铺表单有修改时关闭前提示。规格表同屏显示组合、拼单价、单买价与库存，编码与规格图选填并折叠。图片支持大图与原尺寸查看、添加、替换、移除、前后移动、设主图；补图按轮播、详情、规格用途明确选择，不覆盖同名不同图。选店弹窗可直接添加店铺并保留勾选商品。App 下载模板与运营资料模板一致，网格、单元格边框和填写示例随版本打包。


0.1.36 主页执行进度扩展：沿用既有浅灰背景、白色内容、蓝色主操作和 Mac/Windows 系统字体，属于现有界面的功能扩展。真实 Mac App 已操作旧失败任务“执行记录 → 主页进度弹窗 → 关闭 → 主页重开”，截图覆盖 1320 × 900 与 1024 × 700；正文独立滚动、底部操作可见。12 步骤、队列切换、当前阶段和耗时有源码与目标回归证据；此次截图展示旧失败记录，不代表重新执行或真实六规格保存成功。真实六规格保存、Windows 实机、系统缩放 125%/150% 仍未在本轮验收。详情及证据见《20主页进度与规格确认0.1.36》。
