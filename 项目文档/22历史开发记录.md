# 商品运营台

React + TypeScript + Electron 桌面应用，版本 0.1.45。提供商品资料、店铺管理、执行记录三个页面与本机业务功能。店铺管理参考电商账单的“平台—店铺列表—添加／编辑”结构，目前管理拼多多店铺。已接入默认浏览器草稿执行：沿用当前登录、核对店铺，账号不一致时使用保存的账号密码登录；遇验证码等待运营处理。

更新日期：2026 年 10 月 6 日。

本项目为闭源软件，仓库设为私有，专有代码保留所有权利，详见 [LICENSE](LICENSE)。Windows Setup 安装包在同一私有仓库的 Releases 中下载。数据库、账号配置、浏览器缓存、原始验收记录和真实商品交付文件保留在本机，不纳入仓库。

最新真实六规格验收见 [0.1.41 验证记录](21发布与验证0.1.45.md)。已修正规格异步确认时机和保存后零库存的读回；同一六规格商品连续三轮完整自动执行成功，最后一轮通过已打包 Mac App 操作，22.842 秒完成填写、保存、字段读回和草稿箱确认。

0.1.45：运费模板改为下拉选择，提供两种常用默认模板，并保留导入、已保存的其他模板值和“选店后确认”。左下角先显示本机工作空间，再统一排列浏览器、模型设置、资料目录三个入口。右上角入口和说明弹窗标题统一为“模板下载”。点击“选择文件夹”显示“待开发”弹窗，当前使用“上传 Excel”导入。“下载 Excel 模板”提供空白表格；旁边“下载填写示例”单独提供含两行规格、价格库存和内嵌图片的参考文件。详见 [0.1.45 验证记录](21发布与验证0.1.45.md)。

## 打开应用

Mac Apple Silicon：双击项目根目录的 `商品运营台.app` 快捷入口，或 `release/0.1.45/mac-arm64/商品运营台.app`。本轮输出为 App 文件夹。历史 0.1.19 安装镜像位于 `release/0.1.19/GoodsWorkspace-0.1.19-mac-arm64.dmg`，SHA256 见同目录 `SHA256SUMS.txt`。应用包含 Electron 运行时，不需要安装 Python 或 Node。此包为本机临时签名的内部验证版，尚未完成 Developer ID 签名、公证或其他电脑安装验收。Windows x64 最新安装包位于 `release/0.1.45/GoodsWorkspace-0.1.45-win-x64.exe`，本版完成构建一致性核查，尚未在虚拟机安装；0.1.44 的安装包和虚拟机记录保留，2026-10-06 已在 Windows 11 ARM64 虚拟机中从 0.1.29 实际升级至 0.1.44，完成模板和填写示例下载、示例界面导入与保存、六规格隔离检查、完全退出重启后的资料保留，以及现有浏览器扩展重新连接。尚未覆盖原生 Intel/AMD 电脑，本轮未重跑 Windows PDD 草稿保存，详见 [Windows 虚拟机测试报告](21发布与验证0.1.45.md)。Intel Mac 尚未构建。

正常双击启动使用系统应用数据目录。默认不注入商品或示例账号；商品资料页只提供上传 Excel 与选择文件夹。

## 运营流程

1. 点击“上传 Excel”。“选择文件夹”入口目前显示“待开发”。填写黄色格纵向模板，每个可购买组合填一行规格清单，并在图片清单插入图片。
2. 在识别弹窗核对字段、价格库存和图片。新版单文件 Excel 自动读取内嵌图片，不需要额外上传图片目录。
3. 保存到本机商品库。资料不完整也可保存，补全后才能选店。
4. 勾选本机检查通过的商品，选择店铺；没有店铺时可直接在选店窗口添加。按“店铺名:子账号”填写账号，名称自动生成，保存后自动选中新店铺。
5. 点击“开始填写并保存草稿”。App 在系统默认浏览器打开拼多多，核对店铺，填写商品并分别批量提交轮播图和详情图；两组上传等待重叠，全部取得后台地址后保存草稿，重新打开已保存的编辑页核对字段，再按商品 ID 查询草稿箱、核对状态并截图。
6. 主页进度弹窗显示当前步骤、本次耗时及处理入口；执行记录查看历史结果、原因与日志。验证码完成后继续；保存结果不明时只核对原商品编号，避免重复创建。浏览器需安装 Kimi 浏览器扩展并连接本机桥接服务；App 不另起独立 Chrome 用户目录。

当前 v3 单文件运营模板位于 `运营资料/商品资料模板.xlsx`，保留纵向黄色填写格，包含商品资料、规格清单和图片清单。图片直接插入图片清单对应行，规格图插入 SKU 行。一个 .xlsx 即可交付。旧模板留在历史资料中，不作为默认下载；历史 ZIP 仍可先解压再选择目录。文件夹只含图片时可导入图片并建立待补充资料，价格、库存等须填写，不进行 OCR 猜测。

## 开发运行

本轮使用 Node 24.19.0、pnpm 11.19.0。依赖精确锁定，保留供应链等待期设置；不要为安装新版本关闭该设置。

```sh
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm dev
```

Electron 44 运行时需显式下载一次。受代理网络影响时按环境设置 `ELECTRON_GET_USE_PROXY=1`，不把代理地址或凭据写入项目。

```sh
pnpm build
pnpm test
pnpm pack:mac
pnpm dist:mac
# 在 Windows x64 构建环境执行：
pnpm dist:win
```

包内 Worker、SQLite WASM、图片及模板均被包含。`scripts/dev.mjs` 启动 Vite 和 Electron；纯浏览器打开界面不会伪造本机功能。Mac 开发目录可通过 `GOODS_WORKSPACE_DATA_DIR` 指定隔离测试数据；正常使用无需设置。

## 0.1.13 脚本主流程与异常恢复 Agent

正常执行始终由脚本完成，未配置模型也能运行。Agent 默认只在后台页面、填写页、上传或保存异常后自动接入；本机 Excel 资料问题不调用模型。模型可调用受限恢复工具处理普通通知、等待原表单、重开原编号页面、等待本任务已提交的图片完成；判断可以继续时，自动交回原任务脚本，再继续本批剩余商品。

默认开启异常接入、原页读取和自动继续；设置中可关闭。每任务自动恢复最多一次，失败则保留现场与记录，避免无限重试。Excel 需修改时由运营补充；验证码、权限验证、账号配置变更及工具无法解决的页面变化仍需处理。已尝试保存只回查原草稿，不能通过 Agent 新建商品、改资料、任意执行 JavaScript 或发布。

当前完成本机 HTTP 协议、任务队列及固定恢复代码核查。真实模型连接已通过，正常草稿 1012550849314 完成并读回，单次用时 12.233 秒，未触发 Agent；尚未完成真实模型在 PDD 的异常恢复验收。详见 [异常自动接入与恢复 0.1.13](17异常自动接入与恢复0.1.13.md)。上面的 0.1.12 手动诊断说明为历史版本行为。

## 0.1.14 单独重新登录

店铺管理 → 选择店铺 → 登录与核对 → 退出并重新登录。使用默认浏览器和已保存凭据，依次执行退出确认、切换账号登录方式、填写、一次提交和店铺/子账号核对。每步显示耗时。正常任务仍复用正确登录态。

密码错误、人工验证码、页面或连接异常分别提示。验证码完成后点击“核对登录结果”，只读身份，不重新提交密码。登录不调用模型、不创建商品，与任务和 Agent 互斥。当前资料目录的 `login-records/` 仅记录步骤、状态、耗时及固定提示。

构建、12 项本机登录分支检查、26 文件包源码一致性核验通过。真实 0.1.14 桌面窗口已打开到登录弹窗，保留真实商品、店铺与已加密模型配置。**尚未执行真实退出重登**：浏览器控制会话此前返回 URL 限制，本次控制连接又连续两次超时；未改用其他通道绕过限制。本机检查不代表后台认证成功。

当前验收窗口使用复制自 0.1.13 的 `verification/0.1.14/live-workspace-20261004`，原资料保留。默认双击 App 使用系统默认资料目录，与此验收目录分开。

已保存草稿的历史记录，以及尚未尝试保存的失败记录，不再拦截同一商品在同一店铺的新执行。新任务独立保存商品资料、时间、过程与结果，旧记录保持不变。App 只启动本次新建的任务编号。正在执行、尚未开始、等待处理或保存结果未确认的任务仍需先处理，提示具体原因。创建前检查浏览器、登录和 Agent 是否正忙；更新旧任务资料使用相同的判定。

## 0.1.17 浏览器安装与连接

App 附带官方 Kimi 浏览器扩展 2.0.22 ZIP 及同版本桥接服务（Mac arm64/x64、Windows x64）。启动时检测本机服务与扩展连接，未就绪显示安装教程；侧边栏可随时打开。导出按钮将原 ZIP 和解压文件夹存到用户文档目录，避免 App 升级或临时目录清理导致扩展失效。教程见 [浏览器扩展安装指南](../运营资料/浏览器扩展安装指南.html)。

已有服务优先复用，不自动停止、升级或重启；只接受本机回环地址。扩展未连接不能证明未安装，界面分别说明浏览器关闭、扩展禁用、地址错误、服务不可用和版本不匹配。商品任务创建、启动和店铺登录前再次检测，创建前检测到未连接时不会新建任务；建立后才断连的任务保留为待执行，可在连接恢复后继续。Excel 整理功能仍可用。原任务恢复保留原编号；断连时可从执行记录打开安装入口。官方文件来源与 SHA256 记录在 resources/browser-extension/source.json。Windows 服务文件已随 0.1.19 安装包在虚拟机中启动，安装教程和扩展文件导出通过；扩展实际连接及 PDD 草稿流程尚未在 Windows 验收。

## 0.1.18 简化扩展安装

核实官方扩展 2.0.22 默认自动连接 ws://127.0.0.1:10086/ws。将手动填写地址从必做安装步骤移到“仍未连接”的排查说明，纠正“本地 agent 远程控制”是设置分组而非开启开关的描述。安装文件入口改为打开上一级并选中扩展文件夹；新增独立复制文件夹路径按钮，可直接用于浏览器文件夹选择器。复用已导出文件夹时同步更新其离线教程。

## 0.1.19 下载 Excel 模板

商品资料页的上传区域直接提供“下载 Excel 模板”按钮，点击后选择保存位置。模板随 App 内置，无需联网；包含商品资料、规格清单与图片清单。“模板下载”弹窗里的下载入口继续可用，两个入口共用保存状态与结果提示。
