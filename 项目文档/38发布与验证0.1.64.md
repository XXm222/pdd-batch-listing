# 0.1.64发布与验证

日期：2026-10-09。状态：已正式发布。GitHub Release已设为Latest，服务器在线更新与固定下载均已切到0.1.64。

安装包源码与`v0.1.64`标签对应提交`1f95f3e29a5940159b64e7a587aa4d6301b80e09`；main另含本次发行结果的文档补录，已发布标签不移动。[GitHub Actions](https://github.com/XXm222/pdd-batch-listing/actions/runs/37900706044)的macOS与Windows任务均通过。

## 本版内容

店铺商品导出主区域重构为一个工作面板。店铺选择与读取动作在顶部，数量、列表状态与搜索靠近表格，底部固定显示选中数量、清空选择、失败重试和导出入口。居中空状态、读取骨架、集中错误恢复、缩略图占位、两行标题与单行价格在宽窄窗口中使用同一套布局。

跨页和搜索保留勾选，表头支持部分勾选，重新读取清空旧选择与搜索；超过50件时说明限制并禁用导出，只重试失败商品编号。停止和完成状态分别显示。详情见[导出页重构](37店铺商品导出界面重构.md)。

后台采集、图片下载、Excel/ZIP及IPC继续使用原实现。API导出试验没有并入正式App，试验发现的下架规格状态字段缺口尚未补齐，试验脚本拦截的13件商品不代表正式采集流程已补上该校验，见[API导出验证](36店铺API导出试验.md)。新建拼多多任务继续默认API草稿流程，历史任务按原方式恢复，见[0.1.63记录](35发布与验证0.1.63.md)。

## 验证

- 本版340项自动测试通过；格式、前后端类型检查与Vite生产构建通过。
- 当前React组件已在1320×900与1024×680检查空状态、列表、读取失败、加载和导出进度；跨页搜索选择、50件限制、失败重试、键盘勾选、图片失败与读取重置通过。
- 前端交互使用隔离的fixture服务与此前真实采集的61件商品资料，证明布局和交互；不替代桌面文件选择器或本版真实后台导出。
- Mac ARM64 DMG与Windows x64 NSIS已生成，两平台各63个源码/资源文件与当前构建一致，模板、WASM与导入Worker完整。
- Mac正式包ad-hoc签名深度校验通过；在隔离资料目录实际启动，确认包内file页面、0.1.64版本与新导出空状态界面。没有替换运行中的试用App或业务资料。
- Mac包自身Electron/Node运行时读到0.1.64、darwin/arm64、Node v24.21.0，试用版标记关闭。
- 更新清单用既有密钥签名，与客户端公钥匹配；服务器两包SHA256核对通过。
- 两平台固定下载地址完整下载后，大小和SHA256与本机构建完全一致；公开清单与本地签名清单逐字段一致。以0.1.63作为当前版本参数调用实际更新协议，Mac ARM64和Windows x64均返回0.1.64可更新且签名已验证。这是协议核验，没有替换旧App或执行系统安装。
- GitHub Release的两安装包、SHA256SUMS.txt、LICENSE与NOTICE共五项资产，其服务端摘要和大小均与本机一致；发布后重新查询确认非草稿、非预发布且为Latest。

## 分发与边界

目标为Mac ARM64 DMG与Windows x64 NSIS，同步GitHub Release及`https://www.mandla.cn/goods-updates/latest.json`。使用既有Ed25519更新签名密钥，不更换客户端公钥。原商品资料、账号、图片与记录位于系统应用数据目录，不打包、不迁移或删除。

本版没有重新执行真实店铺采集或后台草稿保存；此前API试验与0.1.63真实读回记录不称作本版重复验收。Mac仍为ad-hoc签名，没有Developer ID签名或Apple公证；Windows包在Mac构建，不替代原生Intel/AMD电脑安装升级验收。

发布与维护操作见[维护交接](33维护交接与更新发布.md)。原始记录留在忽略的`verification/release-0.1.64-20261009/`，不公开商品数据或密钥。
