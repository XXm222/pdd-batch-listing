# 末级类目匹配 0.1.55

商品类目只需填写最后一级名称，例如“足浴盆/足浴桶”。旧资料中的完整路径无需改写，前面的层级不参与匹配。

之前程序按完整路径逐级查找 `li.content-cat`，再跨命令点击 `selectedCate` 元素。分类列表更新后，旧元素可能已消失，出现 `click: element not found`。新流程使用拼多多类目搜索，只点击唯一可见、末级名称完全相同的搜索结果，并核对页面的“已选分类”。同名结果超过一个时停止并提示运营核对。

填写页、恢复原商品填写页、保存前及草稿保存后都从实际“商品分类”栏读取末级名称，不再要求整条路径一致，也不从任意正文文本推断分类。
