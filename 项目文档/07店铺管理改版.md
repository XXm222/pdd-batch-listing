# 店铺管理改版 0.1.1

日期：2026-09-30。按用户“添加店铺学习电商账单的平台”要求实现。

## 参考依据

实际打开 `电商账单项目/Mac测试版/电商账单_中英查询兼容测试版.app`，查看平台区域、平台内店铺列表和天猫添加店铺弹窗；同时读取当前 `源码/app.py` 的 render_accounts / edit_account 实现。本轮未修改电商账单源码、保存店铺或执行账单导出。

参考交互：左侧平台、右侧店铺列表、搜索、添加店铺、编辑登录信息；表单左标签右输入，保留店铺名称、登录账号、登录密码。当前商品运营台业务为拼多多，因此平台显示拼多多。真实其他平台能力、天猫账号格式规则不在本轮范围。

## 本次实现

- 店铺卡片改为平台区与店铺列表，显示本机已保存数量。
- 按店铺名称或登录账号搜索；无匹配时明确提示，并禁用编辑操作。
- 选择店铺后通过“编辑登录信息”或行内“编辑”进入弹窗。
- 添加／编辑弹窗显示所属平台，三个字段横向对齐；打开时聚焦店铺名称。
- 新增检查三个必填字段；编辑密码不回显，留空保留原密文；更换账号需重新填写密码。
- 保存成功选中对应店铺；添加时清空列表搜索，避免新店铺被当前筛选隐藏。
- 提交过程中禁止修改字段，显示保存中；错误留在弹窗中可修正。
- “检查登录”当前禁用并显示说明，未伪造商家登录结果。

## 当前验证

Mac arm64 0.1.1 实际 `.app` 已启动。TypeScript 与 Vite 构建通过。通过真实窗口验证：

| 行为 | 结果 |
| --- | --- |
| 载入旧资料 | 2 商品、1 店铺、1 待执行任务继续保留 |
| 店铺管理 | 平台、列表、计数、搜索、编辑入口与密码保存状态显示正确 |
| 添加弹窗 | 三行表单可打开、取消；空表单保存聚焦名称，填名称和账号后缺密码会聚焦密码，未生成店铺 |
| 编辑留空保存 | 真实提交成功，窗口返回列表；保存前后数据库中的密码密文摘要相同 |
| 搜索 | 无结果显示“没有匹配的店铺”、编辑禁用；清空后恢复原店铺 |
| 最终弹窗 | 提示文案缩短，输入焦点进入店铺名称；保留键盘导航和原生对话框行为 |
| 包内容 | 当前源码构建与应用包逐字节校验，模板、Worker、SQLite WASM 均包含 |

密码保留结果见 `verification/0.1.1/密码保留检查.json`。界面与弹窗截图见同目录。0.1.0 的导入、密码加密、SQLite 与核心测试记录仍保留在《06桌面版验证记录》中；本轮没有使用新密码重新进行系统钥匙串授权，也没有进行真实平台登录。

## 交付与边界

新包位于 `release/0.1.1/`，原 0.1.0 包保留在旧位置。根目录 `商品运营台.app` 快捷入口指向新版。正常启动继续使用系统应用数据目录；本轮窗口使用隔离的 `verification/local-data`，未清空任何资料。

当前版本用于本机界面及资料流程验证；Mac 为临时签名内部包，正式签名、公证、其他电脑安装及 Windows 真机仍待验收。自动登录、切换真实店铺、保存后台草稿与结果读回继续待接入。没有提供正式发布商品入口。
