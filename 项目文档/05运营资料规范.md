# 商品运营台运营资料规范 v3：单 Excel

更新：2026-10-08，适用当前0.1.61；模板格式仍为v3。

运营提供一个.xlsx文件，包含商品资料、规格清单、图片清单三页；图片可在表格内提供，或导入后在软件中补充，一份表格对应一件商品，可以有多个 SKU。无需再提供 images 文件夹或 ZIP，图片名称由软件自动生成。保留四列纵向商品资料和黄色填写格；账号密码在店铺管理维护，表格不填写目标店铺或后台链接。

## 商品资料

适用范围为普通现货实物商品资料，不含预售、定制、二手、卡密商品等特殊流程。填写唯一商品编码、标题、末级类目或完整类目路径、参考价、发货承诺及每 SKU 价格库存。商品编码是软件管理要求；平台参考价必须高于最大单买价。表格和识别页面没有“是否测试素材”字段。

商品品牌应按商品实际情况填写，可暂留空，选店后按该店铺授权品牌确定；不能凭空认定“无品牌”可用。运费模板可以留空，在选店后选择当前店铺的实际模板。满 2 件折扣可暂留空，但后台页面要求配置：执行前必须读取并确认实际折数与折后价格，软件不会自行猜默认值。

材质、适用人群、是否可折叠按类目填写。当前沐浴桶页面把材质标为“重要”，人群与折叠未标平台必填；不能将三项统一认定为所有商品的强制条件。泡脚桶材质可用值包含“塑料”，不要直接把 PP+TPE 材料描述当成已确认的后台选项。其他属性在表格底部填写名称和值，必填性以后台类目要求为准。软件支持最多 50 项，不能重复上方品牌、材质、人群和折叠属性。

当前泡脚桶类目必须支持 7 天无理由退货。正品发票、假一赔十只按实际服务能力填写。服务可选择是、否或按平台规则，执行前核对后台要求。

## 规格清单

一行填一种，比如“紫色＋大号”，最多 100 行。四列为“区分方式1（如颜色）”“具体选项1（如紫色）”“区分方式2（如尺寸）”“具体选项2（如大号）”，再填写该款的价格、库存；编码可选，规格图按目标店铺类目要求提供。旧表头仍可识别。

商品没有可选款式时，这四列都可留空。只按颜色区分时，后两列留空。最多按两种方式区分，每行的区分方式和顺序要一致；区分方式和具体选项同时填写，同一款不要重复填。规格编码选填，有值时不能重复。金额为正数且最多两位小数，拼单价不高于单买价；库存为非负整数，0 有效。规格图可以插入对应行的“规格图”格，也可以在软件“规格与价格”对应行直接添加，不要求必须回Excel补图。是否必填按目标后台类目核对；已实测的沐浴桶/沐浴盆类目要求预览图，其他类目仍需检查实际标记。缺图时软件提前显示数量与补充入口。

当前后台规格类型列表已确认包含“容量”。填写示例展示 10L、20L 两个 SKU，仅用于说明填法；实际使用必须换成真实商品信息和图片。软件已接入多SKU后台草稿填写与读回，但店铺和类目仍按实际后台核验，历史成功样本不代表任意商品均可自动执行。

## 图片清单

每行填写用途和顺序，在“图片”格插入一张图片。轮播图和详情图各自从 1 开始连续编号，未使用的行留空。第一张轮播图为主图。模板连续预留 10 张轮播图、50 张详情图；规格图插入规格清单，无需重复插入图片清单。

推荐在 Excel/WPS 中使用“插入 → 图片 → 浮于单元格”的普通图片方式，将图片左上角放在对应格内，调整显示尺寸使其容易查看。一格一张，保存为 .xlsx。软件从文件内提取原图片资源，不从缩略图截图，不要求填写图片文件名。WPS 批量插图说明见 [WPS 官方操作说明](https://www.wps.cn/learning/room/d/332361)。

读取器支持普通 oneCellAnchor/twoCellAnchor 图片，以及 WPS DISPIMG 和 cellimages 图片关系。非图片公式仍不允许导入。现代 Excel rich-data 置于单元格图片尚未纳入此实现，遇到该格式明确提示改成普通浮动图片；外部链接图片、重复叠图及未放在正确图片列的图片也会提示调整，不自行下载或猜用途。模板生成和本轮真实文件验证使用普通浮动图片；本轮未声称已实机核验所有 Excel/WPS 单元格图片变体。

轮播图：当前填写页要求 PNG/JPEG，1:1 或 3:4、宽高均大于 480px、单张小于3MB，最多 10 张。

详情图：选填，最多 50 张，可使用长图；不套用轮播图的比例限制。当前页面说明不编辑详情时，轮播图会自动填入图文详情。详情与规格图的具体限制在后台分别确认。

## 交付方式

运营交付 `商品资料.xlsx` 一个文件，点击软件“上传 Excel”，即可读取字段、SKU 和内嵌图片。批量商品使用多份编码不同的 Excel，可以一次选择多份。内嵌图片由软件复制至本机资料目录，这个内部目录由软件管理，运营不需要另行准备。

以下文件夹结构仅用于兼容旧资料：

```
本次商品/
  商品A/
    商品资料.xlsx
    images/
      主图.png
      详情图.png
      规格图.png
  商品B/
    商品资料.xlsx
    images/
      主图.png
```

旧文件夹读取能力保留，但当前“选择文件夹”运营入口显示待开发，请多选上传Excel并在软件中补图。旧表格只写图片文件名但未内嵌时，单独上传Excel仍需补图；v3文件已嵌入图片时无需另配图片目录，未提供的图片仍需在软件补充并按目标类目要求核对。

本机读取限制：含图片的单份 Excel 最多 80MB，单张普通图片最多 20MB，一次导入总大小最多 80MB。读取上限与平台上传条件不同；轮播图仍需符合后台的 3MB 等要求。

## 软件流程

上传Excel → 在基本资料、规格与价格、商品图片、发货与服务四分区核对 → 保存本机资料 → 选择店铺 → 开始草稿填写及后台读回。规格名称统一设置，每行保留独立价格库存与图片，切换分区保留修改。资料未补齐可先保存；本机检查通过后可选店。品牌、运费、满件折扣留空时仍需选店后确认。

“本机检查通过”只表示资料格式及本机可核对条件符合。任务仍保留店铺身份、类目和规格选项、品牌资质、运费模板、发货售后、满件折扣及折后价格等待后台核验项。商品资质、包装标签图、白底图及视频尚未纳入自动填写范围。后台身份核验、确定性登录、商品填写及草稿读回已接入；未确认保存结果的任务不得显示为已保存。最新实现与验收边界见 [当前发布摘要](32发布与验证0.1.61.md)。

## 历史兼容

桌面版继续读取 v2 文件夹格式、旧两页纵向表和旧横向清单；旧资料无需迁移删除。默认下载更新为 v3 单文件模板，需要桌面版 0.1.5 或更新版本。旧 Python 执行器没有内嵌图片、多 SKU 和售后执行能力，新格式统一使用桌面版，不能交给旧脚本直接执行。
