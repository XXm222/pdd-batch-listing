# 商品运营台产品需求

运营人员提供商品 Excel 或资料文件夹，软件识别内容并允许核对和修改。确认后先保存商品，再选择店铺执行草稿任务。平台地址、浏览器调试端口和商品内部标识由程序处理。

## 已确认需求

| 项目 | 要求 |
| --- | --- |
| 使用系统 | Mac 和 Windows |
| 导入入口 | 上传 Excel，或选择含 Excel 和图片的文件夹 |
| 运营模板 | 沿用原始商品资料模板，纵向黄色填写格及独立图片清单 |
| 识别结果 | 自动弹窗，展示识别字段、规格价格、库存和图片，可修改 |
| 保存顺序 | 先保存商品资料，再选择执行店铺 |
| 店铺资料 | 店铺名称、登录账号、密码三个业务字段 |
| 登录切换 | 使用所选店铺保存的凭据；保留各店铺独立登录会话 |
| 执行动作 | 第一版保存到草稿箱，不直接发布 |
| 界面效果 | 简洁、精致，商品图片与关键操作优先展示 |

## 商品资料流程

1. 点击上传 Excel 或选择文件夹。选择文件夹时自动寻找受支持模板，并按图片清单匹配图片。
2. 识别后弹出结果，显示商品数量、规格数量及需补充项目。
3. 运营核对字段、价格和图片。错误要定位到商品及字段，保留已识别内容。
4. 保存资料到本机资料库。缺少非身份字段时可保存为待补充；商品编码必须存在且唯一。
5. 勾选本机检查通过的商品，选择已保存的店铺；可以在选店窗口直接添加店铺。Excel 不包含目标店铺。
6. 保存绑定目标店铺和商品版本的本机待执行任务，开始执行后自动打开主页“商品执行进度”弹窗。后台执行链路负责检查登录、核对实际店铺、打开新增商品页、填写并保存草稿；进度展示本次商品队列、当前件、当前阶段、12 个步骤及逐步耗时。收起后可从主页重新打开；暂停须等待当前操作退出，恢复仍沿用原任务的保存核对规则。
7. 保存结果须经后台资料与草稿箱核对后才显示为已保存。异常、保存结果待核对及处理入口展示在主页进度弹窗；执行记录保留店铺、商品、历史结果、原因、时间与日志。0.1.36 的真实六规格草稿保存尚未重验，界面与回归通过不代替后台保存验收。

保存本机资料与保存后台草稿是两个不同步骤，各自显示明确状态。

## 三个业务页面

**商品资料**包含导入区、本机商品列表、识别编辑弹窗、字段提示、商品选择和店铺选择。列表展示图片、标题、规格、价格和资料状态。支持搜索、完整与待补充筛选。 主页承接当前执行进度：任务开始时自动打开弹窗，关闭或收起后保留“查看执行进度”入口，异常处理、暂停与继续执行均在该弹窗完成。

**店铺管理**包含新增和编辑店铺、登录状态、重新登录及打开店铺浏览器。添加表单只有名称、账号、密码；编辑时密码不回显，留空表示保留，修改账号后需重新确认凭据和实际店铺身份。实际后台店铺标识自动获取。

**执行记录**仅展示已完成或已停止的任务，包括目标店铺、草稿结果、失败原因、停止步骤、分步耗时、日志及保存核验信息；排队、执行中和 Agent 正在处理的任务在主页查看。“在主页打开任务”链接到主页进度弹窗处理。历史记录不拦截从商品资料发起的新执行，新任务使用当前商品资料与所选店铺，不继承旧任务的商品编号或保存状态。当前执行中的任务互斥。继续原任务时，保存结果未知仍先核对原草稿。支持单条清理、勾选清理、清理全部；清理仅收起本机记录，可在“已清理”中单条或批量恢复，不删除商品资料、店铺、图片或后台草稿。

## 异常处理

- 表格缺少字段或图片：标记具体项目，允许补充后重新校验。
- 商品编码重复：识别窗口立即提示，保存前核对已有资料与本次资料，明确选择更新已有商品或跳过。更新保留商品标识，待执行任务保留创建时的资料版本。
- 未保存修改：商品和店铺表单关闭、取消或 Esc 时，若内容有变化，提供继续编辑、放弃修改和保存三个选择。
- 密码错误：停止该店铺任务并提供编辑凭据入口。
- 验证码、短信或扫码：暂停，打开实际浏览器让运营处理，验证通过后继续。
- 实际店铺与目标店铺不符：禁止写入，要求重新登录正确店铺。
- 保存请求超时：先核对草稿箱，再决定是否重试；不能把超时直接判定为未保存。
- 取消任务：停止后续商品；已保存的草稿保留并显示结果。

## 第一版范围

当前支持一件商品一份 Excel、嵌入图片及每件最多 100 个可购买组合的本机识别与保存。模板兼容旧版与新版规格编码表头，预留 20 行不限制实际读取。后台草稿执行链路已在源码中接入；0.1.36 的原生规格输入与组合核对补强已通过目标回归，真实六规格草稿保存尚未重验，仍须按实际店铺类目完成后台验收。

类目和属性适配必须按真实店铺权限验证。原型里的资料完整只表示字段检查通过，不代表任意类目均可直接写入后台。

OCR、任意 Excel 自动理解、图片生成、批量改价、云同步、团队权限和直接发布不进入第一版。
