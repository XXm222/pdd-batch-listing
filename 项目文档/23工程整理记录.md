# 工程整理记录 · 0.1.46 开发版

> 本文保留该历史版本的实现与验收记录。当前交付、支持范围和未验证项见 [0.1.61发布与验证摘要](32发布与验证0.1.61.md)。

日期：2026-10-06。按“格式与 CI → 关键页面脚本 → UI 和错误诊断”顺序整理源码。商业功能继续只保存商品草稿；淘宝、京东仍为适配中。本次不重新打包或改动现有 0.1.45 Release，也不迁移用户资料。

## 1. 格式与 CI

- 精确锁定 Prettier 3.9.9，加入 EditorConfig、格式命令与 Git LF 换行规则。
- 统一 src、electron、tests、scripts 及工程配置的格式，独立提交。
- 首轮 CI 发现 Windows 检出换行差异及 Linux 不属于桥接支持平台；修正换行规则，将检查矩阵定为应用实际支持的 macOS、Windows。
- CI 执行冻结依赖安装、格式检查、双 tsconfig 类型检查、全部测试和 Vite 构建。GitHub Actions 使用固定提交 SHA、只读权限。

## 2. 关键页面脚本与数据校验

- `electron/platforms/pdd-page-scripts.ts` 提供自包含的规格表、远端图片及保存设置读取函数。函数由 TypeScript 检查，再序列化到浏览器执行。
- 在主进程接收结果时验证表格单元格与控件结构、图片 URL、保存字段类型；结构异常保留原页并停止处理。
- 继续通过真实 rowspan 稀疏 DOM 夹具运行表格读取、定位、填值和规格图片关联检查。
- 草稿零库存的响应入口改用 unknown，异常响应无法作为零库存证据。原商品/提交编号、完整组合、价格与编码的严格核验保留。
- BrowserBridge 的后台地址由平台传入，保持 HTTPS 和原域名核对；call/eval 默认返回 unknown，evaluate 响应先检查结构。
- 本次抽出上述三条关键读取路径，其他页面表达式仍有字符串实现；并非全部浏览器脚本已迁移。

## 3. UI 与错误诊断

- 商品筛选、分页、可执行选择集集中到 `src/product-list.ts`，保持跨页选择和待补充商品限制。
- 任务全量加载和实时事件的版本合并集中到 `src/workspace-state.ts`，防止旧数据覆盖新状态、已删除记录被事件复活，并保留商品快照。
- 模板说明弹窗独立为 `TemplateDownload.tsx`；前端初始版本不再硬编码，加载后使用 Electron 实际版本。
- Agent 超长系统提示拆为段落数组；八种诊断条件组合的提示正文逐字一致。
- 网络、图片读取、导入 Worker 等错误保留内部 cause。IPC 和任务持久化故障写入现有操作记录文件；诊断只记录允许的异常类别与系统错误码，不记录原始消息、地址、堆栈或凭据。
- 诊断文件写入失败时输出固定结构的脱敏提示，不把已经提交成功的业务操作改报失败。保留有明确降级含义的 catch，并补充扩展导出相关的处理说明。

## 验证与边界

本机格式检查、两个 tsconfig 类型检查、240 项自动测试和构建通过。新增测试覆盖畸形浏览器返回、脚本序列化、零库存响应、目标域名约束、跨页选择、任务版本乱序、诊断脱敏及日志写入失败。CI 结果以对应提交的 GitHub Actions 为准。

创建了仅含填写示例、没有店铺和任务的独立资料库，并启动源码测试进程。桌面工具读取窗口和应用列表均超时，因此本轮原生界面检查未完成；测试进程已结束，原用户资料未改动。本轮未进行真实商家后台保存，也未重跑 Windows 安装或更新现有发布包。

原始检查日志和隔离资料保存在本机 verification/engineering，不上传业务数据库或浏览器运行数据。
